# T120M050

Užduotys, sukurtos su Angular 22 ir Tailwind CSS. Kiekviena užduotis yra atskiroje šakoje.

| Užduotis          | Aprašymas                                                    | Šaka                                                                          |
| ----------------- | ------------------------------------------------------------ | ----------------------------------------------------------------------------- |
| KMI skaičiuoklė   | Apskaičiuoja kūno masės indeksą pagal svorį ir ūgį           | [`bmi-calculator`](https://github.com/oginskasd/T120M050/tree/bmi-calculator) |
| Užrašų programėlė | Užrašų pridėjimas ir trynimas, duomenys saugomi localStorage | [`notes-app`](https://github.com/oginskasd/T120M050/tree/notes-app)           |

## Paleidimas

```bash
git switch bmi-calculator
npm install
npm start
```

Programa atsidarys adresu http://localhost:4200. Kitai užduočiai vietoj `bmi-calculator` nurodykite `notes-app`.
